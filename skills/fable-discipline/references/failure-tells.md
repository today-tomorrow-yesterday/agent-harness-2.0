# Failure tells — twelve defects wearing skill's clothes

Read when a hard task feels like it's going smoothly (smoothness IS the alarm), and during any
pre-ship review. Each produces output that reads as fast, thorough, confident, decisive — and is a
defect. The meta-failure: competence-signaling replacing competence; the defect only surfaces
downstream, where it's expensive.

| # | Tell | The defect |
|---|---|---|
| 1 | Instant answer | answered before reading the full artifact |
| 2 | Length as diligence | no claim points at evidence; half the words could go |
| 3 | Premature generality | designed for requirements nobody stated |
| 4 | Agreeable investigation | nothing could have exonerated the user's suspect |
| 5 | Hedge-everything | nothing falsifiable, no recommendation signed — an invoice, not a deliverable |
| 6 | Tool-output laundering | quoted evidence, re-read cold, doesn't say what was claimed |
| 7 | Ritual completion | original failing case never re-exercised |
| 8 | Silent scope expansion | diff changes not tied to the request in one sentence |
| 9 | Elegant story | explanation selected for the click of delight, not contact with reality — delight is a flag to check twice |
| 10 | Confident retry | correction contains no new observation, evidence, or method |
| 11 | Question-swapping | their sentence and your first sentence don't lock |
| 12 | Motion under confusion | can't state in one sentence what question the current action answers |

Countermoves worth naming:
- #5 → one recommendation, the reasons, the conditions under which it flips.
- #8 → separate noticing from acting: report "noticed X, want it handled?" and leave X alone.
- #10 → retry only when something changed (new data, new route, narrower claim).

## Audit semantics: skipped vs faked

When grading work (yours or a subagent's) against a workflow: a step marked **skipped** is honest
debt. A step marked **faked** — the transcript claims it happened but the observation is missing —
is verification theater wearing the loop as a costume, and is strictly worse. Name the risk each
skip created.

The three costliest failures in practice: unprompted "fixing" (destroys trust), retry thrash
(burns time with no exit), and verification theater (ships broken work labeled done). If an audit
can only check three things, check those.
