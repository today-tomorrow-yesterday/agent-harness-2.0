# forge/

Machine-readable operational logs. Written by the system; read by Skill-Forge and analytics scripts.

| File | What it is |
|---|---|
| `skill-usage.jsonl` | Per-invocation log of every skill called. Written by the `PostToolUse` usage-logger hook. Forward-only — activates after first session restart. |
| `evolution.jsonl` | Append-only changelog of every change to `memory/`, `skills/`, or settings. Written by `session-reflect` (Step 5), Skill-Forge, and direct Claude edits per the evolution log convention. Schema: `{ts, strategy, asset, what, why, session}` |
| `report-latest.md` | Most recent Skill-Forge Phase 0 signal report. Auto-generated by `bin/skill-refiner.py`. |

These files are gitignored — they accumulate personal operational history. Initialize them empty when setting up on a new machine.
