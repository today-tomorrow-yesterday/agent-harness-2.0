# Ideas

Pre-project concepts — captured liberally, graduated to `projects/` selectively.

The rule: **capture everything, promote nothing until you're actually working on it.**

## File format

```markdown
---
name: idea-slug
description: One-line hook
type: idea
captured: YYYY-MM-DD
---

# Idea Title

[What it is — 2-3 sentences]

## Why it's interesting
[The insight or opportunity]

## What would need to be true to graduate this to a project
[The gate conditions]
```

## _index.md

Keep a running `_index.md` as a scratchpad catalog:

```markdown
# Ideas Index

| Idea | Captured | Status |
|---|---|---|
| [idea-title](idea-slug.md) | YYYY-MM-DD | parked / active / graduated |
```
