# Projects

One file per active project. Each file is a living brief — updated as the project evolves.

## File format

```markdown
---
name: project-slug
description: One-line summary
type: project
last_updated: YYYY-MM-DD
---

# Project Name

## What it is
[1-2 sentences]

## Why it exists
[The motivation — what problem does it solve, or what goal does it serve]

## Current status
[Where you are right now]

## Next action
[The single most important next step]

## Key decisions made
[Decisions that are locked and shouldn't be re-litigated without cause]

## Open questions
[Decisions that still need to be made]

## Cross-references
- [[related-rule-or-project]]
```

## Bootstrap

For each active project you have, create a file here.
Ask yourself: if Claude joined this project cold, what would it need to know in 5 minutes?
